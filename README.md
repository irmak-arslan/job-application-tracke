## JobTrack — Job Application Tracker

JobTrack is a responsive web application designed to help students and job seekers organize and manage their job applications in one place.

The project was developed using HTML, CSS, and vanilla JavaScript, with a focus on usability, responsive design, and browser-based data management.

## Features

- Add new job applications
- Edit and delete existing applications
- Search applications by company or position
- Filter applications by status
- Track applications using dashboard statistics
- Store application data using localStorage
- Responsive layout for desktop and mobile devices

## Technologies Used

- HTML5
- CSS3
- JavaScript (ES6+)
- Web Storage API (localStorage)

## How to Run

1. Clone or download this repository.
2. Open the project folder.
3. Open `index.html` in a web browser.

No installation or external dependencies are required.

## How It Works

Users can enter job application details, including the company name, position, job type, location, application date, status, and notes.

Applications are displayed in a table and can be searched, filtered, edited, or deleted.

Dashboard statistics update automatically whenever application data changes.

All application data is stored locally in the user's browser using localStorage. No backend server or user authentication is required.
